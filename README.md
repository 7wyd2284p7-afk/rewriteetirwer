# 回译室

新概念英语电脑回译练习网站。当前包含新概念英语 2 的 Lesson 1 至 Lesson 96，以及新概念英语 3 的 Lesson 1 至 Lesson 60，可从课程库切换教材和课程。

## 已有功能

- 打开网站先进入首页；可选择第二册或第三册、浏览前几课、打开完整课程库，并从上次学习的课程继续。
- 在课程页点击左上角 RE:WRITE 返回首页。
- 点击“开始回译”后，光标自动进入无提示输入区。
- 回译期间不显示英文原文。
- 点击“完成回译”后，在输入文本下方显示英文对照区。
- 可通过“原文”打开只读窗口，并拖动窗口标题移动位置。
- 课程库可切换第二册和第三册；第二册按课数分段，桌面端双列显示课程。
- 草稿和完成状态保存在当前浏览器中；英文原文始终读取当前课程的数据。
- 课程数据按教材存放在 `src/lessons/nce2.js` 和 `src/lessons/nce3.js`，以后新增教材时继续按册拆分。
- 完成后按单词智能对齐比较，漏写一个单词不会导致后文连续错位。
- 错写或多写的单词在回译中整词标红；原文中的对应错词、漏词或格式错误加橙色下划线。
- 结果分别统计错词、漏词、多词和格式错误，并据此计算准确率。
- 大小写不同计为错词；单词之间的空格、单词内部的连字符、问号和感叹号计为格式错误。
- 逗号、句号、引号和换行不计错；漏写问号或感叹号时只在原文相应符号处显示橙色下划线。
- 页面使用响应式布局，支持现代版 Safari、Chrome、Edge，适配 iPhone、iPad、Mac 和 Windows。
- 中文每段首行缩进两个汉字宽度，使用加大的 2.55 倍行距。

## 本地预览

Windows 用户双击“打开回译室.cmd”即可启动，浏览器会自动打开。也可以在项目目录运行 `npm start`，然后访问 `http://127.0.0.1:4173`。
